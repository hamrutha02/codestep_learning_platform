Python Variables

Variable na oru container mathiri. Athula namba values-a (numbers, names) store panni vechukkalam, thevai padum pothu use pannikalam.

🎬 Thalapathy Movie Example

Beast movie-la hero-va oru name vechu kupduvanga la? Adhe madhiri dhaan oru variable-ku name kuduthu data-va store pannuvom.

Syntax

variable_name = value

Example Code

name = "Vijay"
age = 30
print(name)
print(age)
▶ Show Output 
Vijay
30

Explanation

name-la "Vijay" string store agudhu, age-la number store agudhu. Equal sign (=) use panni value-a assign pannrom.

Python Data Types

Data types na entha madhiri value oru variable-la irukku nu pakkarathu (number-ah, text-ah nu).

🎬 Thalapathy Movie Example

Leo movie-la ovvoru object-kum oru type irukum la? Adhe madhiri dhaan Python-layum data types iruku.

Syntax & Example Code

name = "Vijay"       # str
age = 30             # int
height = 5.9         # float
is_actor = True      # bool

print(type(name))
print(type(age))
▶ Show Output 
<class 'str'>
<class 'int'>

Explanation

str is for text, int is for numbers, float is for decimals, and bool is for True/False.

Conditional Statements

Conditions na oru decision edukkurathu. Ithu true-ah irundha oru code work aaganum, false-ah irundha inoru code work aaganum.

🎬 Thalapathy Movie Example

Theri movie-la situation-ku thaguntha madhiri character decisions edukum la? Adhe madhiri dhaan if-else conditions.

Example Code

mark = 75

if mark >= 50:
    print("Pass")
else:
    print("Fail")
▶ Show Output 
Pass

Explanation

Mark 50-ku mela iruntha "Pass" print aagum, illena "Fail" print aagum.
