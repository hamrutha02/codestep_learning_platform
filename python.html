Python Variables

A variable is a name used to store information in a program. We can store numbers, names and other values inside variables. The value can be used later in the program. Python automatically identifies the type of value stored.

🎬 Movie Example - Beast

In Beast, the main character is identified by his name. Similarly, a variable stores information using a name. For example, a variable called hero can store a character name.

Syntax

variable_name = value

Example Code

name = "Vijay"
age = 30

print(name)
print(age)
▶ Show Output 
Vijay
30

Code Explanation

name stores the text Vijay. age stores the number 30. The equal symbol assigns a value to a variable. print() displays the stored values.

Python Data Types

Data types describe what kind of information a variable contains. Python has different data types for numbers, text and collections. Choosing the correct data type helps us store and work with information properly.

🎬 Movie Example - Leo

In Leo, different objects and details have different meanings. Similarly, Python uses different data types to represent numbers, text and true-or-false values.

Syntax

age = 20
name = "Vijay"
price = 99.5
is_student = True

Example Code

name = "Vijay"
age = 30
height = 5.9
is_actor = True

print(type(name))
print(type(age))
print(type(height))
print(type(is_actor))
▶ Show Output 
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>

Code Explanation

str stores text. int stores whole numbers. float stores decimal numbers. bool stores True or False. type() identifies the data type.

Conditional Statements

Conditional statements help a program make decisions. The program checks whether a condition is true or false. If the condition is true, one block of code executes. Otherwise, another block can execute. Python uses if, elif and else for decision-making.

🎬 Movie Example - Theri

In Theri, the character makes different decisions depending on the situation. Similarly, an if statement allows a program to choose what to do based on a condition.

Syntax

if condition:
    statement
else:
    statement

Example Code

mark = 75

if mark >= 50:
    print("Pass")
else:
    print("Fail")
▶ Show Output 
Pass

Code Explanation

The variable mark contains 75. The condition checks whether mark is greater than or equal to 50. Since the condition is true, Pass is displayed. Otherwise, Fail is displayed.

Python Loops

Loops are used to repeat a block of code multiple times. Instead of writing the same statement again and again, we can use a loop. Python supports for loops and while loops.

🎬 Movie Example - Bigil

In Bigil, a team works together repeatedly to practise and improve. Similarly, loops repeat instructions until the required number of repetitions is completed or a condition becomes false.

Syntax

for variable in range(number):
    statement

Example Code

for i in range(1, 4):
    print(i)
▶ Show Output 
1
2
3

Code Explanation

range(1, 4) produces the numbers 1, 2 and 3. The loop runs three times. Each time, the value of i changes. print(i) displays the current value.

Python Functions

A function is a reusable block of code that performs a particular task. Functions help us organize code and avoid repeating the same instructions. Python uses the def keyword to create a function.

🎬 Movie Example - Sarkar

In Sarkar, the main character takes action to solve a problem. Similarly, a function is created for a task and called whenever that task needs to be performed.

Syntax

def function_name():
    statement

function_name()

Example Code

def greet():
    print("Welcome to Python")

greet()
▶ Show Output 
Welcome to Python

Code Explanation

def creates a function. greet is the function name. The print statement is inside the function. greet() calls the function and displays the message.
