Introduction to C++

C++ is a general-purpose programming language. It is an extension of the C language. C++ supports procedural programming and object-oriented programming. It is used to develop applications, games, and software systems. The cout statement displays output on the screen.

    return 0;

Variables

    return 0;
}

Explanation

int is the data type. marks is the variable name. 95 is the stored value. cout displays the variable value.

Conditional Statements

Conditional statements help a program make decisions. The if statement checks a condition. If the condition is true, the if block executes. Otherwise, the else block executes.

🎬 Thalapathy Movie Example

In Theri, decisions depend on situations. Similarly, if-else statements choose which block of code should execute.

Syntax

if (condition) {
    // true block
} else {
    // false block
}

Example Code

#include <iostream>
using namespace std;

int main() {

    int mark = 75;

    if (mark >= 50) {

        cout << "Pass";

    } else {

        cout << "Fail";

    }

    return 0;
}
▶ Show Output 
Pass

Explanation

mark is 75. The condition mark >= 50 is true. Therefore, the program displays Pass. If the condition is false, the else block displays Fail.

Loops

Loops repeat a block of code. The for loop is useful when we know how many times a task should repeat. A loop contains initialization, condition, and update.

🎬 Thalapathy Movie Example

In Leo, repeated practice helps a team improve. Similarly, loops repeat instructions until the condition becomes false.

Syntax

for (initialization; condition; update) {
    // statements
}

Example Code

#include <iostream>
using namespace std;

int main() {

    for (int i = 1; i <= 3; i++) {

        cout << i << " ";

    }

    return 0;
}
▶ Show Output 
1 2 3

Explanation

The loop starts with i = 1. It runs while i <= 3. i++ increases the value by one. The output is 1 2 3.

Classes and Objects

C++ supports object-oriented programming. A class is a blueprint used to create objects. A class can contain variables and functions. An object is an instance of a class. Classes help organize related information and behavior together.

🎬 Thalapathy Movie Example

In Bigil, each player has information and responsibilities. Similarly, a class groups related data and functions together.

Syntax

class ClassName {
public:
    // members
};

Example Code

#include <iostream>
#include <string>
using namespace std;

class Student {

public:

    string name;

    void display() {

        cout << name;

    }

};

int main() {
 Student s;

    s.name = "Vijay";

    s.display();

    return 0;
}
▶ Show Output 
Vijay

Explanation

Student is the class name. name is a data member. display() is a member function. s is an object of Student. The object calls display() to print the student's name.
