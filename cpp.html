🎬 Thalapathy Movie Example

#include <string>
using namespace std;

12.5
A
Vijay

Conditional Statements

Program-la decision edukka conditional statements use pannuvom. Condition true-na oru block run aagum, illena `else` block run aagum.

🎬 Thalapathy Movie Example

Theri movie-la situation-ku etha madhiri decisions edupanga la? Adhe madhiri dhaan if-else statements work aagum.

Example Code

#include <iostream>
using namespace std;

int main() {
    int mark = 75;

    if (mark >= 50) {
        cout << "Pass";
    } else {
        cout << "Fail";
    }
    return 0;
}
▶ Show Output 
Pass

Explanation

Mark 50-ku mela irukura nala condition true aagi "Pass" output varuthu.

Classes and Objects

Class na oru blueprint madhiri. Athula variables and functions-a group panni vechukkalam. Antha class-la irundhu create panrathu dhaan Object.

🎬 Thalapathy Movie Example

Bigil movie-la coach podura game plan oru Class (blueprint) madhiri; athai ground-la play pandra ovvoru player-um Objects madhiri.

Example Code

#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    string name;
    void display() {
        cout << name;
    }
};

int main() {
    Student s;
    s.name = "Vijay";
    s.display();
    return 0;
}
▶ Show Output 
Vijay

Explanation

Student oru class. s antha class-oda object. Object moolama `display()` function-a call pannrom.
