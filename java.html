Introduction to Java

Java is a programming language used to develop applications, websites, and software. Java supports object-oriented programming. A Java program starts execution from the main() method. The System.out.println() statement displays output on the screen.

In Master, characters follow instructions to complete their tasks. Similarly, a Java program follows instructions written by the programmer.

Syntax

class Main {
    public static void main(String[] args) {
        // statements
    }
}

Example Code

class Main {
    public static void main(String[] args) {

        System.out.println("Hello, CodeStep!");

    }
}
▶ Show Output 
Hello, CodeStep!

Explanation

class defines a class. Main is the class name. main() is the starting point. System.out.println() displays output.

Variables

A variable is a named memory location used to store a value. Variables help store information such as marks, age, and names. The value stored in a variable can be used in a program.

🎬 Thalapathy Movie Example

In Sarkar, votes are counted and stored. Similarly, Java variables store values that can be used in calculations.

Syntax

dataType variableName = value;

Example Code

class Main {
    public static void main(String[] args) {

        int marks = 95;

        System.out.println("Marks = " + marks);

    }
}
▶ Show Output 
Marks = 95

Explanation

int is the data type. marks is the variable name. 95 is the stored value. The + operator joins the text and the variable value.

Data Types

Syntax

double price;
char grade;
String name;

Example Code

class Main {
    public static void main(String[] args) {

        int count = 3;

        System.out.println(count);
        System.out.println(price);

    }
}
▶ Show Output 
3
12.5
A
Vijay

Explanation

int stores whole numbers. double stores decimal numbers. char stores one character. String stores text. println() displays each value on a separate line.

Conditional Statements

Conditional statements help a program make decisions. The if statement checks a condition. If the condition is true, the if block executes. Otherwise, the else block executes.

🎬 Thalapathy Movie Example

In Theri, decisions depend on situations. Similarly, if-else statements choose which block of code should execute.

Syntax

if (condition) {
    // true block
} else {
    // false block
}

Example Code

class Main {
    public static void main(String[] args) {

        int mark = 75;

        if (mark >= 50) {

            System.out.println("Pass");

        } else {

            System.out.println("Fail");

        }

    }
}
▶ Show Output 
Pass

Explanation

mark is 75. The condition mark >= 50 is true. Therefore, the program displays Pass. If the condition is false, the else block displays Fail.

Quiz 3

Correct! 75 >= 50 is true, so Pass is displayed.

Wrong! The mark is greater than or equal to 50, so the condition is true.

Loops

Loops repeat a block of code. The for loop is useful when we know how many times a task should repeat. A loop contains initialization, condition, and update.

🎬 Thalapathy Movie Example

In Leo, repeated practice helps a team improve. Similarly, loops repeat instructions until the condition becomes false.

Syntax

for (initialization; condition; update) {
    // statements
}

Example Code

class Main {
    public static void main(String[] args) {

        for (int i = 1; i <= 3; i++) {

            System.out.print(i + " ");

        }

    }
}
▶ Show Output 
1 2 3

Explanation

The loop starts with i = 1. It runs while i <= 3. i++ increases the value by one. The output is 1 2 3.

Quiz 1

What does a loop do?

Correct! A loop repeats a block of code.

Wrong! A loop repeats code; it does not delete it.

Quiz 2

Which part checks whether to continue?

Correct! The condition determines whether the loop continues.

Wrong! The update changes the loop variable.

Quiz 3

How many times does the loop run from 1 to 3?

Correct! The values are 1, 2, and 3, so it runs three times.

Wrong! The loop executes for all three values: 1, 2, and 3.

Classes and Objects

Java supports object-oriented programming. A class is a blueprint used to create objects. A class can contain variables and methods. An object is an instance of a class. Classes help organize related information and behavior together.

🎬 Thalapathy Movie Example

In Bigil, each player has information and responsibilities. Similarly, a class groups related data and methods together.

Syntax

class ClassName {
// variables

    // methods

}

Example Code

class Student {

    String name;

    void display() {

        System.out.println(name);

    }

}

class Main {

    public static void main(String[] args) {

        Student s = new Student();

        s.name = "Vijay";

        s.display();

    }

}
▶ Show Output 
Vijay

Explanation

Student is the class name. name is a variable inside the class. display() is a method. s is an object of Student. The object calls display() to print the student's name.

Quiz 2

Wrong! A loop repeats code. An object is created from a class.

Quiz 3

Correct! The class keyword defines a class in Java.

Wrong! object is not the keyword used to define a class.
