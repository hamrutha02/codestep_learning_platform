Classes and Objects

Class na oru blueprint. Athula variables and methods-a group pannalam. Antha class-kku create panra instance-dhaan Object.

🎬 Thalapathy Movie Example

Bigil movie-la coach podura game plan oru Class (blueprint) mathiri, and ground-la play panra players Objects mathiri.

Example Code

class Student {
    String name;
    void display() {
        System.out.println(name);
    }
}

class Main {
    public static void main(String[] args) {
        Student s = new Student();
        s.name = "Vijay";
        s.display();
    }
}
▶ Show Output 
Vijay

Explanation

Student oru class. s = new Student() use panni object create pannrom, apram `display()` method-a call panrom.
