Introduction to C

C language romba power-ana oru programming language. Ellarume padikira base language-nu sonna adhu C dhaan. C program always `main()` function-la irundhu dhaan start aagum.

🎬 Thalapathy Movie Example

Master movie-la characters ella instructions-ayum step-by-step follow pannuvanga la? Adhe madhiri dhaan C programum namba ezhuthura step-by-step instructions-a follow pannum.

Syntax

#include <stdio.h>

int main(void) {
    // statements
    return 0;
}

Example Code

#include <stdio.h>

int main(void) {
    printf("Hello, CodeStep!");
    return 0;
}
▶ Show Output 
Hello, CodeStep!

Explanation

stdio.h library input/output-ku use aaguthu. main() thaan program-oda starting point, marrum printf() screen-la text-a display pannum.

Data Types

Data types variables enna madhiri values store pannanum nu specify pannum (whole numbers, decimals, characters).

🎬 Thalapathy Movie Example

Bigil movie-la ovvoru player-kum oru role irukum la? Adhe madhiri C-layum ovvoru data type-kum oru role iruku.

Example Code

#include <stdio.h>

int main(void) {
    int count = 3;
    float price = 12.5;
    char grade = 'A';

    printf("%d\n", count);
    printf("%.1f\n", price);
    printf("%c", grade);
    return 0;
}
▶ Show Output 
3
12.5
A

Explanation

int stores integers, float stores decimals, and char stores single characters.

Quiz

Correct! char is for single characters.

Wrong! int is for integers.

Conditional Statements

Conditions program-ku decisions eduthu thara help pannum (if true, run this; else run that).

🎬 Thalapathy Movie Example

Theri movie-la character situation-ku etha mathiri decision edukum la? Adhe mathiri if-else statements use panrom.

Example Code

#include <stdio.h>

int main(void) {
    int mark = 75;

    if (mark >= 50) {
        printf("Pass");
    } else {
        printf("Fail");
    }
    return 0;
}
▶ Show Output 
Pass

Explanation

Mark 50-ku mela iruntha "Pass" print aagum, illena "Fail" print aagum.
