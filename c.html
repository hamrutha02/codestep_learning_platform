Introduction to C

C is a general-purpose programming language. It is used to write programs and solve problems. A C program starts execution from the main() function. The printf() function displays information on the screen.

🎬 Thalapathy Movie Example

In Master, characters follow instructions to complete a task. Similarly, a C program follows instructions written by the programmer.

Syntax

#include <stdio.h>

int main(void) {
    // statements
    return 0;
}

Example Code

#include <stdio.h>

int main(void) {
    printf("Hello, CodeStep!");
    return 0;
}
▶ Show Output 
Hello, CodeStep!

Explanation

stdio.h is used for input and output. main() is the starting point. printf() displays text. return 0 indicates successful completion.

Variables

A variable is a named memory location used to store a value. Variables can store numbers and other information that can be used in a program.

🎬 Thalapathy Movie Example

In Sarkar, votes can be counted and stored. Similarly, variables store values such as marks, age, and count.

Syntax

data_type variable_name = value;

Example Code

#include <stdio.h>

int main(void) {

    int marks = 95;

    printf("Marks = %d", marks);

    return 0;
}
▶ Show Output 
Marks = 95

Explanation

int is the data type. marks is the variable name. 95 is the stored value. %d displays an integer.

Data Types

Data types specify the type of value stored in a variable. int stores whole numbers. float stores decimal numbers. char stores a single character.

🎬 Thalapathy Movie Example

In Bigil, different players have different roles. In C, data types also have different roles based on the values they store.

Syntax

int count;
float price;
char grade;

Example Code

#include <stdio.h>

int main(void) {

    int count = 3;
    float price = 12.5;
    char grade = 'A';

    printf("%d\n", count);
    printf("%.1f\n", price);
    printf("%c", grade);

    return 0;
}
▶ Show Output 
3
12.5
A

Explanation

%d displays an integer. %f displays a decimal number. %c displays a character. \n moves the output to the next line.

Conditional Statements

Conditional statements are used to make decisions in a program. if checks whether a condition is true. else runs when the condition is false.

🎬 Thalapathy Movie Example

In Theri, decisions depend on situations. Similarly, if-else statements choose which block of code should run.

Syntax

if (condition) {
    // true block
} else {
    // false block
}

Example Code

#include <stdio.h>

int main(void) {

    int mark = 75;

    if (mark >= 50) {
        printf("Pass");
    } else {
        printf("Fail");
    }

    return 0;
}
▶ Show Output 
Pass

Explanation

mark is 75. The condition mark >= 50 is true. So the program displays Pass.

Loops

Loops repeat a block of code. A for loop is useful when we know how many times we want to repeat a particular task.

🎬 Thalapathy Movie Example

In Leo, repeated practice helps a team improve. A loop repeats instructions until its condition becomes false.

Syntax

for (initialization; condition; update) {
    // statements
}

Example Code

#include <stdio.h>

int main(void) {

    for (int i = 1; i <= 3; i++) {
        printf("%d ", i);
    }

    return 0;
}
▶ Show Output 
1 2 3

Explanation

The loop starts with i = 1. It runs while i is less than or equal to 3. i++ increases the value by one. So the output is 1 2 3.

Functions

A function is a reusable block of code that performs a particular task. Functions help organize a program and avoid writing the same code repeatedly.

🎬 Thalapathy Movie Example

In Mersal, different people handle different responsibilities. Similarly, a function performs a specific task in a program.

Syntax

return_type function_name(parameters) {
    // statements
    return value;
}

Example Code

#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int main(void) {

    printf("%d", add(4, 3));

    return 0;
}
▶ Show Output 
7

Explanation

add() receives two integer values. It adds them and returns the result. add(4, 3) returns 7.
